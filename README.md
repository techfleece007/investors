# Trading Dashboard

A fullstack dashboard application for inventory and profit management, built with Next.js, TypeScript, Tailwind CSS, and Supabase.

## Features

- **Simple Authentication**: Easy login for two investors (Shady & Tamer) - no external dependencies
- **Product Management**: Add, edit, and delete products with variants (size, stock, price, cost)
- **Order Management**: Create orders with automatic stock updates and profit calculations
- **Shipment Tracking**: Monitor shipment status (pending, shipped, delivered)
- **Expense Tracking**: Manage business expenses with categorization
- **Profit Analytics**: Visual charts showing profit distribution (80% Shady, 20% Tamer)
- **Responsive Design**: Mobile-first design that works on all screen sizes
- **Dark Theme**: Modern dark theme with consistent styling

## Tech Stack

- **Frontend**: Next.js 14 (App Router), TypeScript, Tailwind CSS
- **Backend**: Supabase (PostgreSQL, Auth, Real-time)
- **Charts**: Recharts for data visualization
- **Icons**: Lucide React
- **Styling**: Custom CSS variables with dark mode support

## Prerequisites

- Node.js 18+ 
- npm or yarn
- No external dependencies required for authentication

## Setup Instructions

### 1. Clone and Install Dependencies

```bash
git clone <repository-url>
cd trading-dashboard
npm install
```

### 2. Database Setup

1. Create a new Supabase project
2. Set up the required database tables (products, orders, shipments, expenses, etc.)
3. The schema includes:
   - `investors` table for investor information (Shady & Tamer)
   - `products` table for product information
   - `product_variants` table for size, stock, price, and cost
   - `orders` table for order tracking with automatic payment fees calculation
   - `shipments` table for delivery tracking
   - `expenses` table for cost management
   - `profits` table for profit records (auto-generated by triggers)

### 3. Authentication

The app uses simple authentication with predefined users:
- **Shady**: prvyit@gmail.com / pr (80% profit share)
- **Tamer**: qudaih.tamer@gmail.com / ta (20% profit share)

No external authentication service required!

### 4. Run the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Key Features Explained

### Authentication
- Login-only system (no signup)
- Protected dashboard routes
- Automatic redirect to login for unauthenticated users

### Product Management
- Grid layout for product display
- Add/edit/delete products and variants
- Image support via URL
- Stock and price tracking

### Order System
- Create orders from available product variants
- Automatic payment fees calculation (Cash: 0%, Card: 2.9% + 1 AED + 0.5% VAT, Tabby: 6.99% + 1.5 AED + 6 AED + 0.5% VAT)
- Automatic stock reduction via SQL triggers
- Profit calculation and recording

### Profit Distribution
- 80% Shady, 20% Tamer split based on net profit after all deductions
- Net profit = Total Revenue - Delivery Fees - Payment Fees - Product Costs - Business Expenses
- Visual charts (pie chart, line chart, bar chart)
- Time-based filtering (week/month/year)
- Product performance analytics
- Investor shared amounts tracking (shipments + expenses)

### Responsive Design
- Mobile-first approach
- Collapsible sidebar for mobile
- Responsive tables and grids
- Touch-friendly interface

## Database Triggers

The system uses SQL triggers to automatically:
- Decrease stock when orders are created
- Calculate and record profits
- Maintain data consistency

## API Endpoints

All data operations are handled through Supabase:
- **Products**: CRUD operations for products and variants
- **Orders**: Create orders with automatic updates
- **Shipments**: Track delivery status
- **Expenses**: Manage business costs
- **Profits**: View profit analytics
